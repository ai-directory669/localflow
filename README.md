## ✨ Features

- 🔒 **100% Offline** - Your data never leaves your computer. Complete privacy guaranteed.
- 🤖 **Local LLM Support** - Works with Ollama, LM Studio, llama.cpp. Run any open-source model.
- 📄 **Document Q&A** - Ask questions to your PDFs, DOCX, TXT files instantly.
- 💻 **Code Review Assistant** - AI-powered code analysis without uploading to cloud.
- 📝 **Auto Documentation** - Generate README, API docs automatically. Save hours of work.
- ⚡ **Fast & Lightweight** - No heavy dependencies. Starts in seconds.
- 🎨 **Beautiful UI** - Clean, modern interface. Easy to use for everyone.
- 🆓 **Completely Free** - Open source, no paid features, no subscriptions ever.

## 🚀 Quick Start

### Installation (3 Easy Steps)

```bash
# Step 1: Clone the repository
git clone [https://github.com/aiforwork/localflow.git](https://github.com/aiforwork/localflow.git)
cd localflow

# Step 2: Install dependencies
pip install -r requirements.txt

# Step 3: Run the application
python main.py
```

### One-Click Install (Coming Soon)

Pre-built executables for Windows, Mac, and Linux will be available in the [Releases](https://github.com/aiforwork/localflow/releases) section.
